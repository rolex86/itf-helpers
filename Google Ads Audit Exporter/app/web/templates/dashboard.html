Přístupy a účet

Všechno se ukládá lokálně do `.env` a `config.yaml`.

Merchant Center

Volitelný modul pro Shopping a PMax feed diagnostiku. Google Ads export bez něj funguje dál.

Merchant API používá stejný OAuth client a refresh token, ale token musí mít scope https://www.googleapis.com/auth/content.

    GA4

    Volitelný modul pro engagement, funnel a revenue bez BigQuery exportu.

    GA4 modul používá standardní Analytics Data API a Analytics Admin API. Potřebný scope je https://www.googleapis.com/auth/analytics.readonly.
    Stav přístupu Neotestováno

      Dostupné properties

      Search Console

      Volitelný modul pro organické dotazy, stránky a překryv SEO/PPC.

      Search Console modul používá Search Console API se scope https://www.googleapis.com/auth/webmasters.readonly a lokální cache, aby zbytečně neopakoval stejné drahé dotazy.
      Stav přístupu Neotestováno

        Dostupné properties
        Seznam se načte po kliknutí na tlačítko.

        Google Tag Manager

        Read-only kontrola tagů, triggerů, proměnných a základní diagnostika měření.

        GTM modul používá pouze read-only scope https://www.googleapis.com/auth/tagmanager.readonly. Nic nepublikuje ani neupravuje.

        Zkus test přístupu nebo načti dostupné GTM účty a kontejnery.

          Vybraný účet a kontejner
          Zatím nic.
          Dostupné účty a kontejnery
          Seznam se načte po kliknutí na tlačítko.

          PageSpeed Insights

          Technická kontrola jen nad nejdražšími landing pages, ne nad celým webem.

          Modul bere jen top landing pages podle spendu, vysledky cacheuje lokalne a bez API keye muze fungovat omezeněji. V free-only rezimu nema vyzadovat billing.

          Nulté pravidlo: aplikace má zůstat v lokálním a neplaceném režimu.
